# Оперативная панель управления

Веб-интерфейс для мониторинга оперативной обстановки по тревожным сигналам, экипажам и событиям смены.

Проект имитирует работу диспетчерской панели службы реагирования: отображает активные инциденты, статус экипажей, журнал событий и аналитическую информацию по смене.

---

# Функционал

Панель включает несколько разделов:

### Главная панель
- текущая статистика смены
- активные тревоги
- статус экипажей
- оперативная информация

### Инциденты
- список активных сигналов
- фильтрация по статусам
- добавление нового сигнала
- таймер с момента поступления тревоги

### Экипажи
- отображение экипажей на смене
- информация о составе
- транспорт
- смена статуса экипажа

### Журнал событий
- история всех действий смены
- логирование событий
- хронология реагирования

### Аналитика
- обработанные сигналы
- активные тревоги
- среднее время реагирования
- статистика по смене

- адаптивная верстка
